MirthXeno enables high-performance, real-time data processing via a scalable gateway and broker architecture, supporting auto-scaling capabilities.

- javascript

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/MirthXeno.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

To configure MirthXeno, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
